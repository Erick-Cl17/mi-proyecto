Introducción a Git y GitHub

Git es un sistema de control de versiones distribuido que permite a los desarrolladores rastrear cambios en el código fuente durante el desarrollo de software. GitHub, por otro lado, es una plataforma basada en la web que utiliza Git para el control de versiones y la colaboración en proyectos de software. Juntos, Git y GitHub facilitan la gestión de proyectos, la colaboración entre equipos y el seguimiento de cambios en el código.

Conceptos Clave de Git

  • Repositorio (Repository): Es un espacio donde se almacena el código fuente y su historial de cambios. Puede ser local (en tu máquina) o remoto (en un servidor).
  • Commit: Es una instantánea del estado del proyecto en un momento específico. Cada commit tiene un mensaje descriptivo que explica los cambios realizados.
  • Branch (Rama): Es una línea de desarrollo independiente dentro de un repositorio. Permite trabajar en nuevas características o correcciones sin afectar la rama principal.
  • Merge: Es el proceso de combinar cambios de diferentes ramas en una sola rama.
  • Clone: Es la acción de crear una copia local de un repositorio remoto.
